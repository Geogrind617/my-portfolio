Projects & Practical Experience

Some of the projects and practical experiences that helped me develop my technical abilities.

Gym Equipment Ecommerce Website

This was tasked back when I was in college, it was a project of mine for web development. I made a ecommerce website for selling gym equipment. I used HTML, CSS, and JavaScript for the front-end and MySQL for the back-end. The website had a user-friendly interface, a shopping cart, and a payment gateway. It was a great learning experience for me as I got to apply my knowledge of web development and database design.

Library Management System

This project was bit similar to the Gym Equipment Ecommerce Website since I mainly used the same computer languages to code it but what separate it is the use of a different IDE. I used Visual Studio Code for the Gym Equipment Ecommerce Website while I used Visual Studio Community 2019 for the Library Management System. It was a bit overwhelming using Visual studio community since I was unfamiliar with the many features it had, but with time I was able to get around and made it happen. The project consist of a Booking System for a Library, where users can get a reservation for a book and the system will keep track of the availability of the books.

Library Management System(Android version)

This was an extension of the Library Management System project, but made compatible for andriod devices. I used the same IDE and Xamarin forms along with C# programming language. This was made in mind in order for the client or customers to check the availability of the books in the library and make a reservation for it. This also functions as a tool for admins to manage the books and the reservations made by the users.
